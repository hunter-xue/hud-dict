# macOS 悬浮词典 — 实现决策记录

本文档记录在需求评审中确认的实现决策，用于消除 `macos-hud-dictionary-requirements.md` 中未明确或存在歧义的点。若与需求文档冲突，以需求文档为准；本文档只做澄清与补充。

状态：已确认，作为第一版实现依据。

## 1. 工程与技术选型

- 工程形态：Xcode 工程（`.xcodeproj`），不用 Swift Package Manager。
- 沙盒：**不使用** App Sandbox。原因：Keychain 与 Application Support 的行为更简单，第一版无沙盒需求。
- App 名：`HudDict`。
- Bundle ID：`com.example.huddict`。
- 最低部署目标：macOS 14。
- 菜单栏应用：`Info.plist` 设 `LSUIElement = true`。

## 2. 分层边界

- `HUDPanel`：仅 AppKit。窗口显示/隐藏/置顶/透明度/拖动/不激活。
- `ExplainClient`：**不得 import AppKit**。组提示词、流式请求、切分译文与讲解。
- `WordBook`：**不得 import AppKit**。记词、计数、最近查询时间、Markdown 字符串生成。
- 兜底检查：`grep -r "import AppKit" HudDict/ExplainClient HudDict/WordBook` 应为空。
- 导出与文件选择：`WordBook` 只负责生成 Markdown **字符串**；`NSSavePanel` 与写文件动作放在窗口层（`WordBookUI`）。

## 3. 流式输出协议

- **保留流式**（需求第 5 节要求"先出译文，讲解接着出"），不改需求。
- 提示词约定模型按 `译文内容` + 分隔标记 + `讲解内容` 输出。
- 分隔标记：单独一行的 `<<<SPLIT>>>`。不使用 `---`，避免与正文破折号/水平线冲突。
- 客户端增量切分：命中分隔标记之前的内容渲染为译文，之后渲染为讲解。只做子串查找与缓冲，不做 JSON 解析。
- 容错：整段流结束仍未出现分隔标记时，降级为"全部内容当作译文"，讲解区留空并在面板给出轻提示；不崩、不误切。

## 4. 目标语言与讲解语言

- 设置中**只暴露一栏"目标语言"**，同时决定译文语言与讲解语言。
- 默认：简体中文（即默认英译中）。
- 讲解语言跟随目标语言，不单独设置（与需求第 8 节设置项一致）。

## 5. 单词本

- 写入时机：**每次查询成功后立即同步写盘**；失败不写。
- 存储：JSON，存放于本机 Application Support 目录，不上传、不同步。
- 写盘失败（磁盘满 / 权限）：不崩溃、不静默丢失，需给出提示或日志。
- 记词判定（用于"只记单词不记句子"）：
  - 收尾空白修剪后**不含空白**，
  - **且** 长度有限：拉丁字母 ≤ 40 字符、CJK ≤ 20 字符，
  - **且** 无句末标点（`。！？.!?` 等）。
  - 三者同时满足才记入；含空白的短语与整句不进单词本。
- 合并规则：同一词合并为一条。拉丁字母大小写不敏感（`Word` == `word`）；中文、日文按原文合并。
- 每条字段：词面（展示最近一次写法）、计数、最近查询时间（覆盖，不保留历史）、最近一次译文（不存讲解全文，不保留旧译文）。
- 排序：计数从高到低，计数相同再按最近查询时间从新到旧。
- 单词本窗口：独立普通窗口，不塞进悬浮小窗；支持按词过滤、删除单条；关掉后可从菜单栏重新打开。

## 6. LLM 设置与密钥

- Base URL：保存时规范化，去掉末尾已有的 `/` 或 `/v1`，避免拼成 `/v1/v1`。
- 模型名：原样放进请求体 `model`。
- API Key：存 Keychain，不进明文配置。
- 界面只显示"已保存 / 未保存"，不明文回显完整密钥。
- 编辑行为：输入框**留空 = 沿用旧密钥**；另设独立"清除"按钮用于删除密钥。
- 连通测试：保存前可发一次短请求；失败原因显示在设置页，不弹系统告警。
- 三项（Base URL、模型名、API Key）缺一不可。未配置完整时**不发请求**，面板提示先完成设置。

## 7. 交互细节

- 面板失去焦点后，点击面板任意处即重新成为 key，可继续打字。
- 取消（提交中）：停止流、**保留已出的内容**、输入框内容保留可重试。
- 空输入：不发请求（忽略或轻提示）。
- 输入长度上限：2000 字符，超限提示。
- 菜单栏图标点击：**固定 toggle 主面板**；设置窗口与单词本窗口各自独立，互不影响。
- 隐藏：Esc 或再次点击菜单栏图标，隐藏不退出进程。

## 8. 持久化策略

- 落 UserDefaults：热键、目标语言、透明度。
- 窗口位置：第一版不做（不作为验收项）。
- API Key：Keychain（见第 6 节）。

## 9. 权限

- 不申请辅助功能（Accessibility）权限。
- 不申请屏幕录制权限。
- 热键使用 Carbon `RegisterEventHotKey`，不使用需辅助功能权限的 `CGEvent` 监听。
- 首次启动不得触发任何权限弹窗。

## 10. 需真机验证的点

- 全屏 Space 上呼出面板后成为键盘焦点、且不切换菜单栏归属（需求验收第 3 条）——仅真机可验收。
- 无边框 + 半透明 + 自绘拖动区域与文本选择的冲突——真机验证。
- 独占全屏游戏不保证可覆盖；无边框全屏在承诺范围内。
